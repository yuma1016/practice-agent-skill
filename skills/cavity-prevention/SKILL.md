# 虫歯予防Skill

## 回答時の必須手順

1. 虫歯に関係する質問を受けたら、回答を作る前に
   `references/cavity_guide.csv`を`read_skill_resource`で読み込んでください。

2. CSVの`keywords`列から、質問に関係する行を探してください。

3. 回答は、該当する行の`answer`列を中心に作成してください。

4. `caution`列に注意事項がある場合は、回答にも含めてください。

5. CSVに書かれていない内容を、確実な情報であるかのように追加しないでください。

6. 病気の診断は行わず、痛み、腫れ、しみる症状などがある場合は、
   歯科医院への相談を案内してください。

7. 回答の最後に、使用した行の`record_id`を次の形式で表示してください。

   参照データ：C001, C003

## 回答形式

- 日本語で回答する
- 最初に結論を書く
- 重要な行動を箇条書きにする
- 難しい専門用語には簡単な説明を加える
- 長すぎる回答にしない
