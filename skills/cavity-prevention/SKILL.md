# 虫歯予防案内

虫歯予防に関する質問では、以下の指示に従ってください。

## 回答内容

次の項目を、利用者が実践しやすい形で説明してください。

1. フッ化物配合歯磨剤を使って、毎日丁寧に歯を磨く
2. 特に就寝前の歯磨きを大切にする
3. 歯ブラシだけでは届きにくい部分には、デンタルフロスなどを使用する
4. 甘い食べ物や飲み物を長時間・頻繁に取る習慣を避ける
5. 定期的に歯科医院で健診を受ける

## 回答ルール

- 必ず日本語で回答する
- 最初に、虫歯を完全に防げるとは限らないものの、リスクを下げられると説明する
- 専門用語を使いすぎず、簡潔に説明する
- 痛み、腫れ、歯がしみるなどの症状がある場合は、歯科医院への相談を勧める
- 診断や治療の断定はしない
- 回答の最後に「（ファイルベースの虫歯予防スキルを使用）」と記載する
